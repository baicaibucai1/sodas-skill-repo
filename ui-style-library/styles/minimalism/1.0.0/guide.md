# 极简主义 · 1.0.0

适用于监控、数据看板和管理后台。视觉参考是 [OpenRouter 的可用性页面](https://openrouter.ai/nex-agi/nex-n2.5-pro#uptime)；[交互样本](demo.html)是独立实现，使用虚构业务数据。双击即可打开。以样本为验收基准，[CSS](style.css)是同一份样式；其中有全局选择器，接入已有框架时按需移植或限定作用域，不要全量覆盖现有页面。

| 维度 | 规则 |
| --- | --- |
| 表面 | 白底 `#fff`；分隔线 `#e6e7e8`、1 px；平面布局，悬浮菜单和反馈可用浅阴影 |
| 文本 | 正文 14 px、行高 1.55；辅助信息 11–13 px；页标题 24 px、区块标题 16 px；数字用等宽对齐 |
| 控件 | 常规按钮高约 32 px、圆角 6 px；数据卡圆角 8 px；控件组间隔 6–8 px、卡片间隔约 14 px |
| 语义色 | 近黑主操作；紫色 `#7624f4` 用于焦点和选中；绿、琥珀、红用于状态，配文字或其他可辨别线索；深色主题沿用相同角色 |
| 栅格 | 桌面内容宽度上限 1280 px，200 px 导航和 24 px 栏间距；窄屏导航重排，表格可在容器内滚动 |

不要加大面积渐变、英雄区、装饰阴影或嵌套卡片；不要把任意高亮都染成紫色。业务内容、菜单结构和图表系列按任务调整。

## 对照状态

- 1440×900：默认页面、三级导航展开、运行检测中的禁用与反馈、图表区域对比和图例隐藏。
- 数据表：搜索和筛选、空结果、选择多行、批量确认；测试新建或编辑抽屉的必填校验、取消、保存和焦点返回。
- 360×800：导航和筛选可换行，表格只在容器内横向滚动，抽屉不超出屏幕。
- 对实际交付涉及的控件检查键盘焦点和深色对比度；同样内容、状态、视口才做像素差异比较。
