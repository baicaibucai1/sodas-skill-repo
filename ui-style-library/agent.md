# Agent handoff: UI Style Library

- To use this skill in a UI task, load [SKILL.md](SKILL.md). This file is maintenance guidance; it does not replace the skill or guarantee automatic loading.
- Positioning: StyleKit is the content source. This repo holds only orchestration, a catalog snapshot, and offline previews. Do not reintroduce copied style bodies, component recipes, or prompts; reference upstream by slug.
- `samples.html` is hand-built from scratch: 12 real style fragments drawn in pure CSS, zero images, zero script. It is the reliable fallback when a previewer blocks scripts or images. Keep it dependency-free.
- `gallery.html` is generated by [scripts/build-gallery.mjs](scripts/build-gallery.mjs) from [gallery-template.html](gallery-template.html): first 24 cards are pre-rendered into static HTML, and every thumbnail is a CSS gradient made from `colors` in `data/catalog.json`. `gallery-standalone.html` is an identical copy for single-file sharing.
- After changing the catalog, run `node scripts/sync-catalog.mjs` then `node scripts/build-gallery.mjs`. Never hand-edit `gallery.html`; edit the template.
- The `data/covers/*.svg` files are retained only as archive. Nothing references them anymore, so a broken or blocked image cannot blank a page.
- Before publishing, run `node scripts/catalog.mjs validate` and `node scripts/catalog.mjs list --limit 3`. Verify in a browser with JavaScript both enabled and disabled, at desktop and 360px widths. Report what you actually ran.
- Never push to a remote or change a project's `.ui-style.json` without the user's request.
